# GO INTO DEEP — Website

## تشغيل الموقع
افتح `index.html` في المتصفح.

## إضافة لقاء جديد
افتح `content.js`، ثم أضف عنصرًا جديدًا داخل `meetings`.
غيّر:
- number
- title
- date
- speaker
- image
- description
- link

ضع صور اللقاءات داخل مجلد `assets`.

## رفع الموقع مجانًا
يمكن رفع المجلد إلى GitHub ثم تفعيل GitHub Pages.
الموقع سيصبح متاحًا على رابط GitHub Pages الخاص بالحساب.
